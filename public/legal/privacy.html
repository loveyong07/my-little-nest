初咏的小窝是初咏的个人网站，在这里分享公开动态和联系方式。你可以直接浏览本站。

浏览本站时

本站在浏览器中保存语言选择和公开动态、账号资料的缓存。动态页的年龄确认只在当前浏览器会话中记住确认结果。你可以通过浏览器设置清除这些记录。如果你使用浏览器自带的翻译功能，浏览器可能会下载语言包。

本站由 Vercel 托管。Vercel 可能处理访问本站的 IP 地址、请求路径和诊断信息，以传输页面、保护服务和排查故障。详情见 Vercel 隐私声明。

公开动态和 Google Drive

本站后台从 X 同步公开的账号资料、帖子和文章，并保存用于展示的内容和媒体。启用 Google Drive 媒体存储时，站点管理员授权后台使用 drive.file 权限，创建及读取应用生成或由管理员明确授权的媒体文件。

这些文件保存在管理员的私有 Google Drive 中。供公开动态展示的媒体由 Vercel 后台读取，并经本站地址提供给浏览器。访问者无需登录 Google，本站也不会请求访问访问者的 Google Drive。Google 授权凭据只保存在后台。

媒体按本站展示需要保留。管理员可在 Drive 中删除对应文件，或在 Google 账号的第三方连接撤销授权。本站对通过 Google API 获取的信息的使用和传输遵守 Google API 服务用户数据政策，包括有限使用要求。

外部链接和联系

打开 X 等外部链接后，访问由对应服务的隐私政策管辖。如果你发邮件给我，我会使用你的邮箱和来信内容处理该事项。有关隐私或内容移除的问题，可以发到 loveyong2007@gmail.com。

当サイトは Vercel でホストされています。Vercel は、ページの配信、サービスの保護、障害の調査のために、IP アドレス、リクエストのパス、診断情報を処理することがあります。詳しくは Vercel のプライバシー通知をご覧ください。

公開投稿と Google Drive

サーバーは公開されているプロフィール、投稿、記事を X から同期し、表示に必要なコンテンツとメディアを保存します。Google Drive をメディアの保存先として有効にすると、サイト管理者が drive.file 権限を付与します。この権限は、アプリが作成したファイルや管理者が明示的に許可したメディアの作成と読み取りに使われます。

ファイルは管理者の非公開の Google Drive に保存されます。公開投稿用のメディアは Vercel 上のサーバーが読み取り、当サイトのアドレスからブラウザーに配信します。閲覧に Google へのログインは不要で、閲覧者の Google Drive へのアクセス権限も求めません。Google の認証情報はサーバー側に保管します。

メディアはサイトでの掲載に必要な期間保存します。管理者は Drive でファイルを削除したり、Google アカウントのサードパーティ接続からアクセス権限を取り消したりできます。Google API から取得した情報の利用と転送は、制限付き使用の要件を含む Google API サービスのユーザーデータポリシーに従います。
